# LARP

Starter files for the LARP project.

## Files
- `loader.lua` — downloads and runs `LARP.lua` from this repository's `main` branch.
- `LARP.lua` — clean starter foundation with basic logging, notification, cleanup, and a Right Shift demo toggle.

## Publish
1. Upload `loader.lua` and `LARP.lua` to the repository root.
2. Keep the branch name as `main`, or edit `RAW_URL` in `loader.lua` if you use another branch.
3. The loader URL is:

   `https://raw.githubusercontent.com/userhahaha582/LARP/main/LARP.lua`

4. After changing `LARP.lua`, the same loader URL will fetch the latest committed version.

Only use scripts and features in Roblox experiences where you have permission. The starter is intentionally a scaffold; it does not include the previous Nebula feature implementation.
